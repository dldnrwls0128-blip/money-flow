# v1.9 연구 (승률·손익비·기대수익)

데이터: `../fetch_data.py`로 받은 일봉·투자자별 매매(2023-06~, 수급 2023-11-30~), 시점별 유동성 필터 20일 평균 거래대금 30억↑.
앞 2/3(~2025-11-13)로 고르고 뒤 1/3(2025-11-14~)은 확인만.

1. `feat2.py` – 날짜별 지표 + 실서비스와 같은 `levels()` 가격선, ATR14
2. `prep.py`, `prep2.py` – 점수 항목, '돈이 몰린다' 후보 정의(거래대금 꾸준·순위 상승·비중·OBV·업종·외국인/기관 등)
3. `sim.py` – 매매 시뮬레이터(numba): 반반 매수(2차 지정가), 1·2차 매도 반반, 손절 우선, 1차 매도 뒤 본전 손절, 최대 20거래일, 수수료·세금 0.23%. 수익률은 계획 금액 대비.
4. `plans.py`, `plans2.py`, `evalr2.py` – 가격선 규칙 격자와 지표(승률·손익비·PF·기대수익·MDD 근사, 반기별)
5. `newscore.py`, `final.py`, `out3.py` – 최종 점수(거래 꾸준 2·외국인·기관 2·오늘 거래대금 2·안정성 2·추세 1·과열 아님 1)와 `analysis.json` 생성
